# 你好，我是 Dobby 👋

我把混乱的研究和 AI 工作流，做成**有来源支撑的 Agent Skills** 与实用、本地优先的工具。

我希望 AI 不只是能用，还要可以检查、可以理解，并且诚实说明自己的边界。

`Agent Skills` · `研究系统` · `本地优先的 AI 工具`

## 最近在做
